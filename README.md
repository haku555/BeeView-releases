# BeeView

**軽快・高画質な Windows 向け画像・PDF ビューア**

高速起動、軽快な操作感で、たくさんの画像が入ったフォルダでも矢印キー一つで
サクサク次々に見ていける画像ビューアです。JPEG/PNG などの定番フォーマットはもちろん、
AVIF・JPEG XL（JXL）・WebP・PDF まで幅広く対応しています。

---

## ダウンロード・インストール

1. このリポジトリの **[Releases](../../releases)** ページを開く
2. 最新版から `BeeView.zip` をダウンロード
3. 好きな場所に展開（解凍）する
4. 展開してできた `BeeView` フォルダの中の `BeeView.exe` をダブルクリックで起動

インストーラーは不要です。管理者権限も不要な、**フォルダごと持ち運び可能（ポータブル）な
アプリ**です。USB メモリに入れて別の PC で使うこともできます。

> `BeeView.exe` は同じフォルダ内の DLL（PDF サムネイル拡張など）と組み合わせて動作します。
> `BeeView.exe` だけを単独でコピーせず、**展開した `BeeView` フォルダごと**同じ場所に
> 置いてお使いください。

> 初回起動時に SmartScreen の警告が出ることがありますが、これは未署名の個人配布アプリに
> 共通して出るもので、ウイルスチェック等の問題があるわけではありません。
> 「詳細情報」→「実行」で起動できます。

### 動作環境

| 項目 | 要件 |
|---|---|
| OS | Windows 10 / 11（64bit） |
| ランタイム | 追加インストール不要（フォルダ内に同梱） |
| WebP / HEIC | Windows 11 は標準対応。Windows 10 は Microsoft Store のコーデック拡張が別途必要な場合あり |

## 主な機能

- **軽快な高速表示**：Direct2D による描画＋先読みキャッシュで、次の画像へすぐに切り替わる
- **削除・移動後は次の画像へ自動移動**：表示中の画像をごみ箱へ移動／画像フォルダーへ移動した際、
  同じフォルダに他の画像が残っていれば自動的に次の画像へ切り替わる
- **対応フォーマット**：JPEG / PNG / GIF / BMP / TIFF / WebP / AVIF / JPEG XL（JXL）／ PDF
- **PDF 表示対応**：パスワード付き PDF も開ける（開く際にパスワード入力ダイアログが表示）。
  PDFファイルは専用の「PDFページ表示モード」で開かれ、ページ単位での閲覧・ページ送りができる。
  見開き表示モードにも対応しており、PDFでも2ページを左右に並べて同時に閲覧可能
  （タイトルバー・タブ名にも両ページの番号を表示、左右の入れ替えにも対応）
- **見開き表示（マンガスプレッド）モード**：2 ページを左右に並べて同時表示。左右の入れ替えにも対応し、
  漫画・コミックを見開きページの通りに読める（PDFのページもこのモードで表示可能）。表示中のフォルダの
  内容が変わった場合（画像の追加・削除・置き換え）も自動で反映される。表示中の2ページ分のファイル名を
  タイトルバー・タブ名にも表示（PDF閲覧モード中は従来通り1つのファイル名を表示）
- **ウェブトゥーンモード**：縦長のマンガ・イラストを継ぎ目なく縦スクロール表示。こちらもフォルダ内容の
  変更を自動で反映。縦スクロール中は画面内でより大きく表示されている画像に応じて、タイトルバー・
  タブ名が自動で追従
- **比較表示モード**：2 枚の画像を並べて／重ねてスワイプ比較。2枚それぞれのファイル名をタイトルバー・
  タブ名に表示。表示状態はアプリを閉じても記憶され、次回起動時に自動で復元される。中央の境界線を
  ドラッグすると自動的にピクセル単位の比較モードに切り替わる（つまみは境界線にカーソルを近づけた
  ときだけ表示）。右クリックメニューから「左を変更」「右を変更」を選べる（ショートカットキーは
  それぞれ `R` / `Shift+R`）。ファイルタブから画像・PDFを開く際は、左右の空いている側へ自動的に
  開かれる。まだ画像を開いていない側の画面をクリックすると、その場でファイルを開くダイアログを
  表示できる
- **アニメーション画像対応**：GIF・WebP・JPEG XL のアニメーションを再生。再生中のフレームを一覧表示して
  好きなコマへ直接ジャンプすることも可能
- **バッチ形式変換**：フォルダ内の画像をまとめて別フォーマットへ変換
- **EXIF 情報表示・GPS 位置を地図表示**
- **画面端ホバーで前後移動**（半透明矢印ナビ）
- **ショートカットキーのカスタマイズ**（設定からキー割り当てを変更可能。項目を選択するとすぐに
  キー入力を受け付ける2段階フローで設定しやすい）
- **タイトルバー・メニューバーの見た目をカスタマイズ**：色を「既定（ライト/ダークモードに追従）」
  「カスタムカラー」「Windows のアクセントカラーに追従」から選べる。ウィンドウがアクティブ／非アクティブの
  状態がひと目でわかるよう自動で色が変化するほか、タイトルバーには現在表示中の画像の
  「親フォルダ名 > ファイル名」が表示される
- **タイトルバー・メニューバーどちらからでもウィンドウ移動が可能**：メニューバーの項目が並んでいない
  余白部分をドラッグしてもウィンドウを移動できるため、タイトルバーとの境目を気にする必要がない
- **拡大率のポップアップ表示**：拡大・縮小操作をすると、現在の拡大率が画面右上に一時的に表示される
- **右クリックメニューを強化**：画像・PDF表示中は表示モード切替・並び順・表示対象の変更に加えて、
  ファイル名/ファイルパスのコピー、ファイルのあるフォルダをエクスプローラーで開く、といった操作に
  すぐアクセスできる。何も開いていない状態での右クリックからもファイルを開く操作一式が行える
- **フォルダ移動機能**：オプション(&T)メニュー、または右クリックメニューから「上の階層に移動」
  「下の階層に移動」を選ぶだけで、画像・PDFが入っている別のフォルダへワンクリックで移動できる
  （候補が複数ある場合はサブメニューから選択）
- **比較表示モードでPDFのページ単位比較に対応**：左右どちらのペインにもPDFを読み込め、それぞれ
  独立してページ送りが可能
- **PDFエクスプローラープレビュー拡張**：設定(&S) > 「PDFエクスプローラープレビュー拡張（右側
  プレビュー枠）...」を有効にすると、エクスプローラーのプレビューウィンドウ枠にPDFの内容を
  そのまま表示できるようになる（任意機能、有効化にはUACの確認が必要）
- **ダウンロードのブロックを一括解除**：ツール(&L)メニュー、または右クリックメニューから
  「フォルダ内PDFのブロックを一括解除...」を実行すると、フォルダ内のPDFすべてについて
  インターネットからダウンロードした際のブロック（Windowsのセキュリティ警告）をまとめて解除できる。
  1つのファイルだけを解除したい場合は、右クリックメニューの「ダウンロードのブロックを解除」から
  個別に解除することも可能
- **画像/PDFの閲覧履歴**：ファイル(&F)メニューから、直接開いたファイルの履歴に画像/PDFそれぞれ
  すぐアクセスできる（保持件数は設定から変更可能）
- **よく見るファイル**：ファイル(&F)メニューに、開いた回数の多い順で自動的に一覧表示
- **ブックマーク機能**：気に入ったファイルを `Ctrl+D` でブックマークに登録/解除。並び替え・削除は
  管理画面からまとめて行える
- **フォルダを開く**：ファイル(&F) > 「フォルダを開く」、またはフォルダ自体のドラッグ&ドロップにも対応
- **画像フォルダー機能**：あらかじめ登録した2つのフォルダーへ、キー操作だけで画像をコピー・移動可能
  （設定(&S) > 画像フォルダー設定... から登録。コピー/移動先に同名ファイルがある場合の挙動
  （連番を付ける／上書き）も設定可能。画像フォルダー1はコピー/移動どちらも、画像フォルダー2は
  コピー（`Shift+Insert`）・移動（`Ctrl+Shift+Insert`）どちらのキーにも対応）
- **タブ表示機能**：1つのウィンドウで複数の画像・PDFをタブとして開いておける（既定でオン、
  設定(&S) > タブバー設定... からオン/オフ可能）。バックグラウンドのタブで開いているファイルが
  外部アプリで上書き保存された場合も、そのタブへ切り替えた際に最新の内容へ自動的に更新される
  - ファイルタブ・エクスプローラー・ドラッグ&ドロップいずれの経路でファイルを開いても、
    「現在の表示モードを維持」「常に通常表示で開く」「常に見開き表示で開く」
    「常にウェブトゥーンモードで開く」のいずれかを選んで開けるよう設定可能
    （設定(&S) > タブバー設定...）
  - タブバー上でマウスホイールを回すとアクティブなタブを左右に切り替えられる
  - タブのドラッグ&ドロップで並び替え、タブバー余白へのドロップでタブを複製（複製先は常に
    一番右側になる）。タブバーの余白部分はタイトルバー同様ドラッグしてウィンドウを移動する
    こともできる
  - タブを画面外へドロップするとその位置に新しいウィンドウとして切り離せる。逆に別ウィンドウの
    タブを現在のタブバーへドラッグ&ドロップで統合することも可能（左端・タブの間・右端どこにでも
    挿入可能）
  - タブバーの右クリックメニューから「現在のタブ以外を閉じる」など、まとめてタブを整理する
    操作も可能
  - **タブグループ機能**：よく使うタブの組み合わせを名前・色付きのグループとして保存でき、
    右クリックメニューやタブバー設定から一括で開き直せる（設定(&S) > タブバー設定 >
    タブグループ設定...）
  - **閉じたタブ・ウィンドウの復元**：閉じたタブ・閉じたウィンドウを何個でも遡って復元可能
    （上限あり）。マウスジェスチャー（右クリックを押しながらマウスを右→左に動かす）でも
    ワンアクションで復元できる
  - **マウスジェスチャー機能**：右クリックドラッグによるジェスチャーに任意のコマンドを割り当て
    可能（設定(&S) > マウスジェスチャー設定...。ダークモードでの表示にも対応）
  - **タブ状態の自動保存・復元**：アプリを閉じても開いていたタブ・ウィンドウ構成を記憶し、
    次回起動時に自動で復元（設定でオン/オフ可能、既定はオン）
  - 複数ウィンドウを開いている場合も、ファイル(&F) > 「すべてのウィンドウを終了」でまとめて
    終了・復元が可能
- **サムネイル表示の高速化（エクスプローラー連携）**：設定(&S) > 「PDF及び画像サムネイル拡張」を
  有効にすると、エクスプローラーのフォルダ表示でPDF・画像のサムネイルがより高速に表示されるように
  なる（任意機能、有効化にはUACの確認が必要）
- **既定アプリへの登録**：対応する画像形式・PDFをまとめてWindowsの「既定のアプリ」の候補として
  登録可能（設定メニューから。エクスプローラーのプロパティ画面からも選択できるようになる）
- **既定アプリ登録の残骸掃除ツール（BeeViewCleanup.exe）を同梱**：既定アプリに登録したまま
  BeeViewフォルダを削除してしまった場合でも、単独で登録の残骸を掃除できる
- **自動アップデート機能**：起動時／メニューから新バージョンの確認・ワンクリック更新が可能

## 基本的な使い方（キーボード・マウス操作）

| キー / マウス操作 | 動作 |
|---|---|
| `→` / `↓` / `Space` / `PageDown` | 次の画像・次のページへ |
| `←` / `↑` / `PageUp` | 前の画像・前のページへ |
| マウスホイール | 前/次の画像へ |
| `+` / `-` | 拡大 / 縮小 |
| `Ctrl` + マウスホイール | カーソル位置を中心に拡大 / 縮小 |
| 左ボタンドラッグ | パン（拡大表示中に画像を動かす） |
| 画面の左端・右端へカーソルを移動 | 半透明の矢印アイコンが表示され、クリックで前/次の画像へ移動 |
| `0` | 原寸大（100%）表示 |
| `1` / `9` | ウィンドウに合わせて表示 |
| ダブルクリック / `F` | ズーム倍率・移動位置をリセット（現在の表示モードに戻す） |
| `F11` / `N` | 全画面表示の切り替え |
| `Delete` | ごみ箱へ移動（確認ダイアログあり） |
| `Shift` + `Delete` | 完全削除（確認ダイアログなし） |
| `Insert` | 画像フォルダー1へコピー |
| `Ctrl` + `Insert` | 画像フォルダー1へ移動 |
| `Shift` + `Insert` | 画像フォルダー2へコピー |
| `Ctrl` + `Shift` + `Insert` | 画像フォルダー2へ移動 |
| `F2` | ファイルを開く |
| `M` | 見開き表示（マンガスプレッド）の切り替え |
| `K` | 見開き表示中、左右ページの入れ替え |
| `W` | ウェブトゥーン（縦スクロール）表示の切り替え |
| `C` | 比較表示モードの切り替え |
| `Ctrl` + `D` | 表示中のファイルをブックマークに追加/解除 |
| `Esc` / `X` | 終了 |

このほかのショートカットや詳しい操作方法は、アプリ内の **設定(&S) > ショートカットキー設定** から
確認・変更できます。

## 既定のアプリに設定する

画像ファイルやPDFをダブルクリックしたときに、常にBeeViewで開くようにしたい場合の手順です。

1. BeeViewを起動し、**設定(&S) > 既定のアプリとして設定...** を選ぶ（画像・PDF両方がまとめて
   登録される）
2. 確認ダイアログで「はい」を選ぶと、BeeViewがWindowsの既定アプリ候補として登録される
3. 続けてWindowsの「設定 > 既定のアプリ」画面が自動で開くので、そこで拡張子ごとに
   「BeeView」を選択する（Windowsの仕様上、この最終選択はユーザーが手動で行う必要があり、
   アプリ側から自動で既定に切り替えることはできません）

登録した内容は、ファイルを右クリック→**プロパティ→変更**からのアプリ選択画面や、
右クリックメニューの**「プログラムから開く」**の候補一覧にも反映されます。

> 登録・解除の直後は候補一覧にBeeViewが反映されないことがあります。これはWindowsが
> 候補一覧を都度キャッシュしているためで、**一度サインアウト→サインインするか、
> タスクマネージャーからエクスプローラー（explorer.exe）を再起動**すると反映されます。

登録を取りやめたい場合は、**設定(&S) > 既定のアプリ設定を解除**から、画像・PDF両方の登録を
まとめていつでも削除できます。他の画像ビューア・PDFリーダーの既定設定には影響しません。

なお、BeeViewのフォルダを別の場所へ移動した場合、次回起動時に自動で新しい場所の情報へ
登録し直されます（削除した場合は登録だけが残るため、上記の解除メニューから手動で削除してください）。

万が一、既定アプリに登録したままBeeViewフォルダ自体を削除してしまった場合は、フォルダ内に
同梱されている `BeeViewCleanup.exe` を実行することで、後から単独で登録の残骸を掃除できます
（BeeView.exe本体が既に無くても、このツール単体で動作します）。

## アップデート方法

- アプリのメニュー **設定(&S) > 更新を確認...** から、いつでも手動でチェックできます
- **起動時にも自動でバックグラウンドチェックが行われます**（新しいバージョンが見つかった
  場合のみ通知ダイアログが表示され、最新の場合は何も表示されません）。この自動チェックは
  **設定(&S) > 起動時に更新を自動確認する** のチェックを外すことで無効にできます（既定は有効）
- 新しいバージョンがある場合はダイアログで通知され、承諾するとダウンロードから
  適用・再起動まで自動で行われます（手動でのファイル差し替えは不要です）
